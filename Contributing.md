## Editing Pages
1. Hit the "Edit this Page" button at the bottom of any page![[Screenshot_20261028_132104_Chrome.jpg]]
2. Sign in to Github
3. Make your edits and hit the green "Commit Changes" button![[Screenshot_20261028_132154_Chrome.jpg]]
4. Write a brief message about what you changed in the commit message. i.e. "Fixed formatting", "Added Water Magic Abilities", etc.![[Screenshot_20261028_132504_Chrome.jpg]]
5. Hit the green "Commit changes" button
6. Wait 2 minutes for the website to sync
7. Your changes are now live on the wiki! Thank you for contributing!
## Making New Pages
1. Go to the github page for this wiki: https://github.com/DJVoxel/deorum-wiki/tree/main
2. Select the folder you want to add a page to. If you want to add a page to the main folder, skip this step
3. Select the More Options menu (...)![[Screenshot_20261028_152408_Chrome.jpg]]
4. Select the "Create New File" option from the dropdown![[Screenshot_20261028_152352_Chrome.jpg]]
5. Name the file however you like, **BUT THE NAME MUST END IN .md OR THE FILE WILL BE IGNORED**![[Screenshot_20261028_152553_Chrome.jpg]]
6. If you are adding a new Species, Magic, or other page with a consistent pattern, check the Templates folder for a template you can copy to the new page to get you started.
7. Once you are finished writing your new file, commit your changes just like you would when [[Contributing#Editing Pages|editing an existing file]].
