## Starter Magic
Starter Magic is available to most species from birth
- [[Magic/Earth]]
- [[Magic/Electric]]
- [[Magic/Fire]]
- [[Magic/Ice]]
- [[Magic/Nature]]
- [[Magic/Water]]
- [[Magic/Wind]]
## Basic Magic
Basic Magic is usually not available birth but has no prerequisites
- [[Magic/Dark]]
- [[Magic/Light]]

- Demonic Modifier - Hell
  - Hellfire
- [[Magic/God Arts]]
- [[Magic/Gravity]]
- [[Magic/Harmony]] - Magic Cores
- Holy Modifier - Heaven
- [[Magic/Merchuka]] - From [[Azuma]]/[[Midi]]
- [[Magic/Time]]
- [[Magic/Void]]
## Universal Techniques
These techniques are available to (almost) every type of magic, but manifest different depending on the type of magic.
- Weapon Enhancement
- Magic Movement (Effect Depends on Magic)
- Orbs
- Buffing
- Debuffing
- Healing
## Tips:
- Give Techniques Names. This allows you to quickly use them in combat without needing to describe the effect every single time.
