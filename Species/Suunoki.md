## Abilities
### Strengths
- Has wings which it can mold with [[Ice|ice magic]]
- Can use stasis to transfer momentum from anything to any other thing, with the effect having diminishing returns for larger changes in momentum
  - This effect is reduced by the target's magic resistance and consumes stamina
  - If momentum is transferred to the user it is more effective

### Weaknesses
- Taking [[Fire]] or [[Electric]] damage reduces magic resistance
- Takes 20% more damage from all magic except [[Ice]] and [[Ice#Sub-Magics|its sub-magics]]
